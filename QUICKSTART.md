## Deploy to Internet (5 Minutes)

### Step 1: Create GitHub Repository
1. Go to https://github.com/new
2. Name it: `microservice-deployment` or `HephaestusForge`
3. Keep it **Public** (required for free Streamlit hosting)
4. Click "Create repository"

### Step 2: Push Your Code
```bash
cd "c:\Users\Pranesh\Downloads\god\HephaestusForge-main(1)\HephaestusForge-main"

git init
git add .
git commit -m "Deployment-ready version"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

Replace `YOUR_USERNAME` and `YOUR_REPO_NAME` with your actual values.

### Step 3: Deploy on Streamlit Cloud (FREE!)
1. Go to https://share.streamlit.io
2. Click **"New app"**
3. Select your repository from dropdown
4. Main file path: `app.py`
5. Click **"Deploy"**

**Done!** Your app will be live in ~2 minutes at:
`https://YOUR-APP-NAME.streamlit.app`
